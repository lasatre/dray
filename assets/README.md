# Bundled assets

Files compiled into the `dray` binary.

- `fonts/JetBrainsMono-Regular.ttf`: JetBrains Mono 2.305, from
  <https://github.com/JetBrains/JetBrainsMono>. SIL Open Font License 1.1, see `fonts/OFL.txt`.
- `icons/*.svg`: Lucide 0.460.0 (`lucide-static`), from <https://lucide.dev>. ISC license, see
  `icons/LICENSE`. Changed from the originals: the stroke is white (`#ffffff`) so the app can
  tint the icons, and the stroke width is 2.25 units, which is 1.5 px at 16 px.

The logo and app icon live in `../brand/logo/`.
