Buttons trigger actions in toolbars, dialogs and empty states; one `primary` per view, everything else `secondary`, `ghost` or `danger`.

The consumer provides a verb-first sentence-case label ("Upload", "Delete 12 files"). Height is 28 px, horizontal padding `space-3`, radius `radius-md`, text `ui-label`. Primary is `brand` fill with `on-brand` text, hover `brand-strong`. Secondary sits on `surface-raised` with a `border-strong` edge. Danger is `danger` text and edge, filled only in the confirm step of a destructive dialog. Every button shows the 2 px `focus-ring` with a 2 px offset on keyboard focus.

Do not put two primaries in one view, use icons without labels for primary actions, or write labels in Title Case.
