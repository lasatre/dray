The Dray lockup: the folder-D mark followed by the name in Schibsted Grotesk bold. Place it on `surface` or `surface-raised` in `brand`, on a `brand` fill in `on-brand`, or on an `ink` fill in `surface`.

The consumer provides the ground and the size. Mark height is 1.2 times the name's cap height, the gap is `space-2`, tracking is -0.03em, and clear space is half the mark's width. Minimum mark size is 16 px; below that show the mark alone.

Do not recolor outside these three pairings, stretch, outline, or set the name in another face. In the dark theme the `brand` pairing uses the lighter dark-theme copper.
