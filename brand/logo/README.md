The Dray mark in three single-ink files, plus the app icon. They are `<img>` assets and cannot inherit color, so pick the file by ground.

- `mark-copper.svg`: ink `#b03e0d` (`brand`, light). Use on `surface` and `surface-raised` in the light theme.
- `mark-ink.svg`: ink `#1b1916` (`ink`, light). One-color print, docs, and light grounds where copper is already used nearby.
- `mark-paper.svg`: ink `#fffdf9` (`on-brand`, light). Use on `brand`, `ink` or dark grounds. In the dark theme, prefer this file or recreate the mark inline in `brand` (`#ee7a46`).
- `app-icon.svg`: copper rounded square (radius 56 of 256) with the paper mark. The only file with a background; use for the OS app icon and store listings.
